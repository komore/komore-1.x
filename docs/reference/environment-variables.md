# Environment Variables

Reference list of environment variable defined by [komore modules].

| Name                                         | Default   | Description                                     |
| :------------------------------------------- | :-------- | :---------------------------------------------- |
| `KOMORE_DOMAIN`                              | _none_    | Domain of the software that is executing        |
| `KOMORE_OBSERVABILITY_LOGGING_AMAZON_PREFIX` | _not set_ | Prefix for CloudWatch Logs group names          |
| `KOMORE_OBSERVABILITY_LOGGING_TRACES`        | _not set_ | Enables recording log events with a trace level |

[komore modules]: ./modules.md
