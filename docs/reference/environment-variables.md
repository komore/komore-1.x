# Environment Variables

| Name                                     | Default   | Description                                     |
| :--------------------------------------- | :-------- | :---------------------------------------------- |
| `KOMORE_DOMAIN`                          | _none_    | Domain of the software that is executing        |
| `KOMORE_OBSERVABILITY_AMAZON_LOG_PREFIX` | _not set_ | Prefix for CloudWatch Logs group names          |
| `KOMORE_OBSERVABILITY_LOGGING_TRACES`    | _not set_ | Enables recording log events with a trace level |
