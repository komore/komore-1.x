## Installation

The `@komore/observability-azure` module is published on the Npm registry.

| Tool | Command                                           |
| :--- | :------------------------------------------------ |
| npm  | `npm install @komore/observability-azure --save`  |
| pnpm | `pnpm install @komore/observability-azure --save` |
| Yarn | `yarn add @komore/observability-azure`            |
