# @komore/temporal

The `@komore/temporal` module helps manipulate temporal structures.

## Key concepts

- [Instants] are immutable values representing a date, a time, or both
- [Durations] are immutable values representing elapsed time
- [Intervals] hold a period of time with a start and end
- [Time zones] determine how geographical information affects an instant
- [Formatting functions] can present temporal information with locale awareness
