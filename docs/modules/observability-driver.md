# Observability Driver

An observability driver is the underlying implementation for the `@komore/observability` API.

## Available drivers

The following drivers are maintained as part of the komore framework.

| Driver                                  | Module                                 |
| :-------------------------------------- | :------------------------------------- |
| [Observability for Amazon Web Services] | `@komore/observability-amazon`         |
| [Observability for Microsoft Azure]     | `@komore/observability-azure`          |
| [Observability for Google Cloud]        | `@komore/observability-google`         |
| [Observability driver - Browser]        | `@komore/observability/driver/browser` |
| [Observability driver - Local]          | `@komore/observability/driver/local`   |
