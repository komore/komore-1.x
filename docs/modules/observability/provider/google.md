# Observability for Google Cloud

The `@komore/observability-provider-google` module implements [observability] using the [Google Cloud platform].

## Key features

- [Cloud Logging] is used to implement logs, log groups and log events
- [Cloud Monitoring] is used to implement metrics
- [Cloud Trace] is used to implement tracing

## Installation

The `@komore/observability-provider-google` module is published on the Npm registry.

| Tool | Command                                                    |
| :--- | :--------------------------------------------------------- |
| npm  | `npm install @komore/observability-provider-google --save` |
| pnpm | `pnpm add @komore/observability-provider-google`           |
| Yarn | `yarn add @komore/observability-provider-google`           |
