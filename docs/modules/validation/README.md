# Validation

The `@komore/validation` module helps validating data.

## Key concepts

- Constraints are applied to data
- Constraint violation errors describe how constraint conditions have not been met

## Installation

The `@komore/validation` module is published on the Npm registry.

| Tool | Command                                 |
| :--- | :-------------------------------------- |
| npm  | `npm install @komore/validation --save` |
| pnpm | `pnpm add @komore/validation`           |
| Yarn | `yarn add @komore/validation`           |
