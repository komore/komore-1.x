# Observability for Google Cloud

The Observability for Google Cloud module integrates with the [Google Cloud] platform:

- [Cloud Logging] for logs
- [Cloud Monitoring] for metrics
- [Cloud Trace] for tracing

## Installation

The module can be installed with Npm or Yarn.

```sh
npm install @komore/observability-google --save
```

```sh
yarn add @komore/observability-google
```
