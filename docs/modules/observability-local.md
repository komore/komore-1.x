# Observability Driver - Local

The `@komore/observability/driver/local` module implements non-distributed, local [observability].

# Key features

The Observability for Local Development module offers a local, non-distributed implementation of observability:

- Logs are sent to the console
- Metrics and traces are stored in memory

## Installation

The module ships with `@komore/observability` and does not need to be installed separately.
