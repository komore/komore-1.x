# Observability for Local Development

The Observability for Local Development module offers a local, non-distributed implementation of observability:

- Logs are sent to the console
- Metrics and traces are stored in memory

## Installation

> :warning: This module is used by `@komore/dev-server` and normally does not require a manual installation

The module can be installed with Npm or Yarn.

```sh
npm install @komore/observability-gcp --save
```

```sh
yarn add @komore/observability-gcp
```
