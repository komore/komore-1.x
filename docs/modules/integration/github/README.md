## Installation

The `@komore/integration-github` module is published on the Npm registry.

| Tool | Command                                         |
| :--- | :---------------------------------------------- |
| npm  | `npm install @komore/integration-github --save` |
| pnpm | `pnpm add @komore/integration-github`           |
| Yarn | `yarn add @komore/integration-github`           |
