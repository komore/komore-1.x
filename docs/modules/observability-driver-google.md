# Observability for Google Cloud

The Observability for Google Cloud module integrates with the [Google Cloud platform]:

## Key features

- [Cloud Logging] is used to implement logs, log groups and log events
- [Cloud Monitoring] is used to implement metrics
- [Cloud Trace] is used to implement tracing

## Installation

The `@komore/observability-google` module is published on the Npm registry.

| Tool | Command                                            |
| :--- | :------------------------------------------------- |
| npm  | `npm install @komore/observability-google --save`  |
| pnpm | `pnpm install @komore/observability-google --save` |
| Yarn | `yarn add @komore/observability-google`            |
