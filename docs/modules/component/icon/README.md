# Icon

The `k-icon` web component can display an icon from an [SVG] or from a font with ligatures such as the [Material font].

## Usage

To use an SVG document as an icon, slot it into the component.

```html
<script type="module">
  import '@komore/component/icon';
</script>
<k-icon>
    <svg xmlns=">
</k-icon>
```
