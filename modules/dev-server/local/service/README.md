# komore Local Development Server - Service

[![NPM version](https://img.shields.io/npm/v/@komore/dev-server-local-service.svg)](https://www.npmjs.com/package/@komore/dev-server-local-service)

Base module for service implementations used with the [komore local development server].

## Install

The module can be installed via Npm or Yarn:

```shell
npm install @komore/dev-server-local-service --save-dev
```

```shell
yarn add @komore/dev-server-local-service --dev
```

[komore local development server]: https://npmjs.com/package/@komore/dev-server-local
