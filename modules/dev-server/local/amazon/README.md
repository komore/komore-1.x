# komore Local Development Server - Amazon

[![NPM version](https://img.shields.io/npm/v/@komore/dev-server-local-amazon.svg)](https://www.npmjs.com/package/@komore/dev-server-local-amazon)

Amazon Web Services implementation for the [komore local development server].

## Install

The module can be installed via Npm or Yarn:

```shell
npm install @komore/dev-server-local-amazon --save-dev
```

```shell
yarn add @komore/dev-server-local-amazon --dev
```
