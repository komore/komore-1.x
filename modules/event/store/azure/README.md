# komore Event Store - Azure

Support for Azure services as [komore] event stores:

- [Azure Cosmos DB]

## Install

The `@komore/event-store-azure` module can be installed via Npm or Yarn:

```shell
npm install @komore/event-store-azure --save
```

```shell
yarn add @komore/event-store-azure
```
