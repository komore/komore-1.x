# komore Authorization

- default is pass-through
- @komore/authorization for the base model
- @komore/authorization/jwt to parse a token and its claims
- @komore/authorization/abac for attribute-based access control
- @komore/authorization/abac/xacml for XACML support (generate TypeScript from XACML rules)
- @komore/authorization/abac/alfa for ALFA support (generate XACML then TypeScript from ALFA rules)
- @komore/authorization/abac/policy-administration-point
- @komore/authorization/abac/policy-decision-point
- @komore/authorization/abac/policy-enforcement-point
- @komore/authorization/testing
