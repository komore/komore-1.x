# komore Observability for Amazon Web Services

Observability module for AWS:

- [CloudWatch Logs] for logs
- [CloudWatch Metrics] for metrics
- [X-Ray] for tracing

## Install

```shell
npm install @komore/observability-amazon
```

```shell
yarn add @komore/observability-amazon
```

## Documentation

Full documentation for the module can be found [here].

[cloudwatch logs]: https://docs.aws.amazon.com/AmazonCloudWatch/latest/logs/WhatIsCloudWatchLogs.html
[cloudwatch metrics]: https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/working_with_metrics.html
