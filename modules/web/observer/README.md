# komore Web - Observer

[![NPM version](https://img.shields.io/npm/v/@komore/web)](https://www.npmjs.com/package/@komore/web)

Base module for service implementations used with the [komore local development server].

## Install

The module can be installed via Npm or Yarn:

```shell
npm install @komore/web --save
```

```shell
yarn add @komore/web --dev
```

[komore local development server]: https://npmjs.com/package/@komore/dev-server-local



- observeIntersections
- mutationObserver
- performanceObserver
- resizeObserver
