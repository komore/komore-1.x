# Installation

The [@komore/function-lambda] module can be installed via Npm, pnpm or Yarn:

```sh
npm install @komore/function-lambda --save
```

```sh
pnpm add @komore/function-lambda
```

```sh
yarn add @komore/function-lambda
```

[@komore/function-lambda]: https://npmjs.com/package/@komore/function-lambda
