# Installation

The [@komore/function-google] module can be installed via Npm, pnpm or Yarn:

```sh
npm install @komore/function-google --save
```

```sh
pnpm add @komore/function-google
```

```sh
yarn add @komore/function-google
```

[@komore/function-google]: https://npmjs.com/package/@komore/function-google
